---
title: Theming
description: Theme Fict shadcn with Tailwind CSS variables.
---

Fict shadcn components use semantic CSS variables such as `--background`, `--foreground`, `--primary`, and `--border`.

```css
:root {
  --background: 0 0% 100%;
  --foreground: 240 10% 3.9%;
  --primary: 240 5.9% 10%;
  --primary-foreground: 0 0% 98%;
}

.dark {
  --background: 240 10% 3.9%;
  --foreground: 0 0% 98%;
}
```

Apply a maintained theme with `npx @fictjs/shadcn@latest theme apply theme-zinc`.
