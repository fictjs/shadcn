---
title: Blocks
description: Install complete Fict page and feature compositions.
---

Blocks are multi-file Fict compositions built from the same builtin component registry.

```bash
npx @fictjs/shadcn@latest blocks list
npx @fictjs/shadcn@latest blocks add dashboard-01
```

Use the [Blocks gallery](/blocks) to inspect previews and the exact Fict files installed by each block.
