# Fict shadcn

This project brings the shadcn source-distribution model to Fict. Components are copied into your application, use Fict JSX and signals, and use `@fictjs/radix-ui` where an accessible primitive is required.

## Quick start

```bash
npx @fictjs/shadcn@latest init
npx @fictjs/shadcn@latest add button dialog
```

Browse the [Fict component catalog](/docs/components/fict/button) or continue with [installation](/docs/installation).
