---
title: CLI
description: Add, update, inspect, and remove Fict shadcn source files.
---

```bash
npx @fictjs/shadcn@latest init
npx @fictjs/shadcn@latest list
npx @fictjs/shadcn@latest search dialog
npx @fictjs/shadcn@latest add dialog
npx @fictjs/shadcn@latest diff dialog
npx @fictjs/shadcn@latest update dialog
npx @fictjs/shadcn@latest remove dialog
npx @fictjs/shadcn@latest doctor
```

The CLI records installed entries and content hashes in `fictcn.lock.json`, allowing updates to detect local edits before replacing source files.
